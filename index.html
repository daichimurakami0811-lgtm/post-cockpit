API設定

APIキーの扱いについて

キーはこのブラウザの localStorage に保存され、リクエストはブラウザから直接 Anthropic / OpenAI に送られます。 このファイルを公開サーバーに置いたり、共有PCで使ったりしないでください。 チームで使うなら、両方のキーをサーバー側（Netlify Functions など）に置いて中継する構成に変えてください。

中継モードでは、下のAPIキー欄は使われません。キーはサーバーの環境変数から付きます。

テロップの合成・スライド・動画の書き出しはブラウザ内で処理します。Anthropicは文章生成と画像解析に使います。

OpenAI（背景画像の生成）

背景ビジュアルの生成だけに使います。日本語テロップと数値はCanvas側で重ねるため、画像には文字を描かせません。 未設定でも、アップロード画像を背景にすれば全機能が動きます。

Webhook連携

作成したJSONを Make / GAS / n8n などへ直接POSTします。 GASのWeb Appはブラウザから直接POSTするとCORSで弾かれるので、 その場合は形式を text/plain にするか、中継経由にしてください。

送信先
X API（OAuth 2.0 PKCE）

XのアクセストークンはGitHub Pagesやブラウザには保存せず、バックエンド側で暗号化して管理します。接続後も各アクションはこの画面で確認してから個別実行します。

取得間隔

Post Cockpitが開いている間、今回この画面から公開したメイン投稿への「登録済み子アカウントからの手動リプライ」だけを監視し、検知したらAIで返信文を生成してメインアカウントのX APIから自動返信します。子アカウントのリプライ自体はAPIでは実行しません。

必要スコープ：tweet.read / tweet.write / users.read / like.write / bookmark.write / offline.access。X側の権限と料金体系はDeveloper Consoleで確認してください。

新着監視を使う場合、バックエンドに POST /api/x/monitor/poll を実装してください。対象ハンドル配列を受け取り、未処理の新着Postを items:[{tweetId,url,authorHandle,authorName,text,createdAt}] 形式で返します。XのFiltered Stream等の常時接続はブラウザではなくバックエンドで維持します。
