Post Cockpit v23

変更点
- アクションの重みを「子アカウントごとの確率」ではなく「親に紐づく有効な子アカウント全体へのアクション数配分」として扱います。
- 例：10アカウント、重み 30/20/10/25/15/20 の場合、比率を10人へ整数配分し、その配分されたアクションを子アカウントへランダムに割り当てます。
- 親アカウントの actionDistribution に設定を保存します。
- v22以前の子アカウント actionPolicy は後方互換で読み込み、親の配分へ移行します。
- いいね／リポスト／保存／見送りは実行指示のみ、リプライ／引用は文案生成対象です。
