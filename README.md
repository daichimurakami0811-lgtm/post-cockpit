# Post Cockpit v25

v24をベースに「アカウント育成デスク」を追加した版です。

## 追加機能
- 子アカウントごとの育成設定
- 投稿テーマ（8種）の選択
- 1日の投稿数・投稿時刻の設定
- ペルソナ／独自プロンプト／直近の育成投稿を使ったAI候補生成
- 3候補の編集
- ローカル育成スケジュール
- X投稿画面を開く（手動）
- X APIバックエンド経由の投稿（既存のOAuthバックエンドが `/api/x/action` の `action: post` に対応している場合）
- 育成データJSONの書き出し

## 注意
GitHub Pagesはブラウザを閉じている間にJavaScriptを実行できないため、v25の「スケジュール」はバックグラウンド自動投稿ではありません。予約キューを保存し、ユーザーが確認して投稿する設計です。

API投稿を使う場合も確認ダイアログを既定で表示します。
