# Post Cockpit v22

GitHub Pagesなどの静的ホスティング向け。

## 構成
- `index.html` : アプリ本体
- `post-cockpit-personas.json` : 外部ペルソナ／アカウント初期データ

## v22変更
- 子アカウントをフォロワー／サポートアカウントとして扱う
- いいね／リポスト／保存／リプライ／引用／見送りを投稿ごとにランダム計画
- リプライは投稿内容への感想・補足・質問・事実ベースのレビューを基本とする
- 引用は紹介・PRまたは要点補足を基本とし、PR／紹介であることを明示する設定を追加
- 架空の利益体験、架空の第三者推薦、架空の口コミを生成しない
- 実行は手動確認前提

APIキーはGitHubへ保存せず、アプリの設定画面からブラウザ内に入力してください。
